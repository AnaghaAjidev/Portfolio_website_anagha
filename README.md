# Anagha Ajidev — Developer Portfolio

A responsive React + Vite portfolio with a midnight visual theme, Three.js constellation background, animated hero, interactive skill orbit, project showcases, education timeline, achievements, certifications and contact links.

## Requirements
- Node.js 18 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Project structure

- `src/main.jsx` — React components, page content, interactions and Three.js scene
- `src/style.css` — responsive visual system, typography, animations and layouts
- `public/` — profile images and downloadable Resume

The site uses Google Fonts (Space Grotesk, Inter and DM Mono). The constellation background uses Three.js and automatically reduces visual motion when the visitor has enabled reduced motion in their operating system.
